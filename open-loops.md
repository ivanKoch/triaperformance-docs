- [ ] **Run a pricing test — the site finally makes it possible.** *(Iván, Aug 6, 2026.)* Units are flat (160 → 170 → ~204 annualised) while average sale doubled ($21 → $49), so **price has been the only working growth lever and it has never been tested deliberately** — it drifted upward as the catalogue changed.
