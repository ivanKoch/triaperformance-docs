**Checkpoints:** quick peek ~Aug 30 (1 month — directional only, traffic is too thin for significance), real read ~Oct 27 (90 days). Conversion is the metric that matters; views should stay roughly flat (titles mostly kept). Sales are NOT in BigQuery — export the TP marketplace sales report for DatePurchased >= 07/30/2026 and join by PlanId.

**Query 1 — cohort before/after views (traffic sanity check):**

```sql
WITH clean AS (
  SELECT plan_id, DATE(event_timestamp) AS d
  FROM `training-plan-analytics.tracking_data.plan_views`
  WHERE event_timestamp >= TIMESTAMP('2026-01-01')
    AND ip_address NOT IN ('181.62.20.182','190.193.3.211','181.86.140.211')
    AND NOT (user_agent LIKE '%GoogleOther%' OR user_agent LIKE '%bot%'
          OR user_agent LIKE '%crawler%' OR user_agent LIKE '%spider%'
          OR user_agent LIKE '%headless%')
)
SELECT
  CASE
    WHEN plan_id IN ('415102','493737','492217','493735','493733','492216','493724','442098','443885') THEN 'EN_rewritten'
    WHEN plan_id IN ('415245','439917','480131','441905','408604','491764','566789','413662') THEN 'ES_rewritten'
    WHEN plan_id IN ('436503','436384','567302','438913') THEN 'PT_rewritten'
    WHEN plan_id IN ('413817','414883','602981') THEN 'CONTROL_sellers'
  END AS cohort,
  IF(d >= '2026-07-30', 'after', 'before') AS period,
  COUNT(*) AS views,
  ROUND(COUNT(*) / (DATE_DIFF(MAX(d), MIN(d), DAY) + 1), 2) AS views_per_day
FROM clean
WHERE plan_id IN ('415102','493737','492217','493735','493733','492216','493724','442098','443885',
                  '415245','439917','480131','441905','408604','491764','566789','413662',
                  '436503','436384','567302','438913','413817','414883','602981')
GROUP BY cohort, period
ORDER BY cohort, period;
```

**Query 2 — per-plan "after" views (join with the sales export for conversion):**

```sql
SELECT plan_id, COUNT(*) AS views_after
FROM `training-plan-analytics.tracking_data.plan_views`
WHERE event_timestamp >= TIMESTAMP('2026-07-30')
  AND ip_address NOT IN ('181.62.20.182','190.193.3.211','181.86.140.211')
  AND NOT (user_agent LIKE '%GoogleOther%' OR user_agent LIKE '%bot%'
        OR user_agent LIKE '%crawler%' OR user_agent LIKE '%spider%'
        OR user_agent LIKE '%headless%')
  AND plan_id IN ('415102','493737','492217','493735','493733','492216','493724','442098','443885',
                  '415245','439917','480131','441905','408604','491764','566789','413662',
                  '436503','436384','567302','438913','413817','414883','602981')
GROUP BY plan_id
ORDER BY views_after DESC;
```
